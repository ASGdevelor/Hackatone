# 🐈 Фотик — AI Manager для ООО «Фотопринт»

**Демонстрационный MVP для хакатона, трек 3.** Цифровой помощник руководителя: задачи, встречи, документы, поиск, KPI, уведомления, PDF-отчёты и чат. В проекте используются **тестовые данные**. Не предназначен для публичного production-развёртывания без аудита безопасности.

## Возможности

- **Роли:** директор, начальник отдела, заместитель. Серверная проверка прав на документы и действия.
- **AI Secretary:** рабочая сводка, встречи, календарь и предложения действий.
- **AI Meeting:** анализ текста совещаний, протокол и поручения с подтверждением.
- **AI Tracker:** задачи, сроки, просрочки, контроль исполнения.
- **AI Documents:** полнотекстовый поиск по демонстрационной базе из 500 документов (SQLite FTS5).
- **AI Control:** KPI, уведомления, расчётный индекс риска и PDF-отчёт.
- **Фотик Chat:** быстрые примеры запросов, поиск данных и ответы в трёх режимах.
- **Аудит:** история операций и подтверждений.

## Технологии и архитектура

Python 3.11+, FastAPI, SQLite + FTS5, HTML/CSS/JavaScript без фронтенд-фреймворка. Сервер `app.py` обслуживает веб-интерфейс `static/index.html`, проверяет сессии и роли, обращается к SQLite, затем выбирает движок ответа. **Внешние модели получают только контекст, отобранный сервером по правам.** Внешние API и Ollama не управляют SQLite напрямую. Изменяющие операции должны подтверждаться пользователем.

```text
Пользователь → веб-интерфейс → FastAPI (сессия, RBAC)
                                    ├→ SQLite (документы, задачи, встречи, аудит)
                                    └→ OpenAI API → Ollama → локальные правила/SQLite
```

## Быстрый запуск на Windows

1. Установите Python **3.11 или новее** и проверьте `python --version`.
2. Скачайте репозиторий (`Code → Download ZIP`) или клонируйте его.
3. Запустите `start.bat`. При первом запуске он создаст `.venv`, установит зависимости из `requirements.txt` и создаст локальный `.env` из `.env.example`.
4. Откройте **http://127.0.0.1:8000**.
5. Проверьте сервер: **http://127.0.0.1:8000/api/health**.

Если порт 8000 занят, остановите предыдущий сервер. Для Linux/macOS предусмотрен `start.sh`.

## Как подключить локальную нейросеть Ollama

1. Установите Ollama: https://ollama.com/download/windows
2. В CMD выполните:

   ```cmd
   ollama pull llama3.2
   ollama list
   ollama run llama3.2
   ```

3. Проверьте, что Ollama работает по `http://127.0.0.1:11434`.
4. В `.env` установите `OLLAMA_URL=http://127.0.0.1:11434` и `OLLAMA_MODEL=llama3.2`.
5. Перезапустите `start.bat` и проверьте `http://127.0.0.1:8000/api/ai/status` после входа.

**Важно:** `ollama pull` скачивает модель, но не гарантирует, что приложение обращается к ней. Проверьте статус и ответы чата. Для работы Ollama после загрузки модели интернет не нужен.

## OpenAI API (по желанию)

Создайте `.env` копированием `.env.example` и заполните **локально**:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
ALLOW_EXTERNAL_AI=true
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2
```

При доступном OpenAI используется облачная модель; при ошибке — Ollama, затем встроенные правила. **При включённом OpenAI текст запроса и отобранные фрагменты документов могут отправляться внешнему провайдеру.** Не используйте реальные конфиденциальные данные без разрешения.

## Без внешней модели

Даже без OpenAI и Ollama работают сервер, роли, документы, KPI, PDF и сценарные ответы на типовые запросы: «Покажи KPI», «Какие задачи просрочены?», «Что я упустил?», «Найди регламент», «Подготовь повестку». Это **правила + SQLite**, а не генеративная модель; произвольные вопросы поддерживаются ограниченно.

## Сценарий демонстрации (5 минут)

1. Войдите директором, откройте KPI и уведомления.
2. В чате задайте «Что я упустил?» и «Какие задачи просрочены?».
3. Найдите документ через поиск и покажите источник.
4. Подготовьте протокол совещания и поручение; подтвердите действие.
5. Покажите PDF-отчёт и журнал аудита.
6. Войдите заместителем и продемонстрируйте ограничения доступа.

## Безопасность и ограничения

- `.env` и секреты исключены из Git через `.gitignore`. **Никогда не коммитьте API-ключи**.
- `data/app.db` содержит **только демонстрационную базу**, включённую намеренно для запуска с примерами; не заменяйте её реальной рабочей БД в публичном репозитории.
- Режим саморегистрации в `.env.example` предназначен только для локальной демонстрации. Перед реальным внедрением отключить, добавить HTTPS, секреты, политику доступа, резервные копии и независимое тестирование безопасности.
- Ответы LLM могут ошибаться; подтверждайте изменения и проверяйте источники.

## Состав проекта

`app.py` — API и бизнес-логика; `static/` — интерфейс; `data/` — демонстрационные документы и SQLite; `requirements.txt` — зависимости; `start.bat`/`start.sh` — запуск; `.env.example` — шаблон конфигурации; `qa_tests.py` и `qa7_tests.py` — проверки.
